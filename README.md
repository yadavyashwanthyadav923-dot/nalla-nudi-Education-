Nalla Nudi Education is an Android application developed using Kotlin and Generative AI technologies to provide smart and interactive learning support for students. The app helps users access study materials, AI-generated notes, quizzes, voice assistance, and personalized educational content in Kannada and English.

Features
AI-generated study notes
Smart quiz generation
Voice-assisted learning
Kannada & English language support
User-friendly Android interface
Personalized learning recommendations
Technologies Used
Android Studio
Kotlin
Firebase
Generative AI APIs
XML UI Design
Purpose

The project aims to improve digital education accessibility and make learning easier, smarter, and more interactive for students.
